# Aggregate exports

This folder contains the aggregate CSV results produced by the SQL analyses:

- `event_audit.csv`
- `unordered_funnel.csv`
- `ordered_funnel.csv`
- `weekly_retention.csv`

These files contain grouped counts and cohort metrics, not raw event records. Keep raw events, credentials, and personal data out of the repository. Re-export the files here when you refresh the analysis.
